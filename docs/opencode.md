# OpenCode Interoperability

There are dozens of AI agents out there, we did not want to reinvent our own.

Each Agent sandbox runs an OpenCode server. The Gateway's OpenCode API is 100%
interoperable with Opencode TUI client. You can connect to the agent you can
thus use,

```
opencode attach https://gw.clawarmor.accuknox.com/api/opencode/{AGENT_NAME}/
```
