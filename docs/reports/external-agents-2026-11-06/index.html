How the integration works

Clients without native gateway OAuth receive a per-profile loopback capability. The relay replaces it with the current inference or MCP audience token; provider keys remain at the provider-owning gateway. Inference and MCP use separate grants and rotating refresh tokens. ChatGPT retains native gateway OAuth in its own Codex profile rather than receiving provider keys.

The local relay rejects browser Origins, hostile Host values and missing/wrong local credentials. It strips cookies and alternative provider-auth headers upstream, flushes streaming responses immediately, and does not follow authentication redirects. File credentials/exports use private modes. Refresh is serialized across processes and pins the original resource. A stale lock fails closed with explicit recovery advice.

Persisted registration types, consent filtering, OpenAPI enums, telemetry handling, deletion/correlation queries and database constraints were updated together. Existing claude and codex identifiers remain unchanged. PostgreSQL migrations were applied in the disposable test database. Observer rollback refuses incompatible retained telemetry instead of deleting audit history.

Research findings that changed the implementation

Use the native interfaces for each product

ChatGPT shares native provider settings with Codex and supports separate gateway OAuth. The implementation persists configuration in an isolated profile, merges existing preferences and launches the actual desktop executable. The headless Linux test needed an unlocked Secret Service default collection; its private test keyring is not a production keyring deployment. Gateway documentation · Linux app.

Claude desktop's import format differs from flat MDM settings. The accepted export uses $schemaVersion:2, nested inference credentials, an explicit model lineup and optional native managed MCP with a credential helper. The model route retains its Claude identity. The first-run landing composer did not start the Code session; choosing New entered the native Code environment flow, where folder trust was confirmed. Native configuration workflow · Configuration contract.

GitHub Copilot CLI's custom tools require native Responses or native Anthropic Messages. An initial Chat Completions attempt failed on a custom tool; the adapter now selects a native protocol and isolates inherited provider settings. The installed CLI sent store:false with explicit history. The separate native desktop supports BYOK after GitHub sign-in; an API inference key does not bypass that sign-in. CLI BYOK · Desktop providers · Official desktop releases.
